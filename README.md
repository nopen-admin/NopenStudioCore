# Nopen Studio Core

Nopen Studio Core, Fedora üzerinde başlayan, konsol tabanlı ve yerel-öncelikli bir asistan çekirdeği projesidir.

## Durum

İlk geliştirme görevi W001 ayrı bir feature dalında yürütülmektedir. Bu `main` dalı, kod içermeyen başlangıç referansıdır. Worker kodu yalnız Draft Pull Request üzerinden değerlendirilerek alınacaktır.

- [Ürün sözleşmesi ve güvenlik sınırları (#1)](https://github.com/nopen-admin/NopenStudioCore/issues/1)
- [W001 görev ve kabul ölçütleri (#2)](https://github.com/nopen-admin/NopenStudioCore/issues/2)

## Güvenlik

Ekran izleme, bilgisayar kontrolü ve ağ üzerinden veri aktarımı varsayılan olarak kapalıdır. Bu özellikler henüz uygulamaya alınmış sayılmaz. Yetki ve gizlilik sözleşmesi Issue #1'de tanımlıdır.

Bu depoya kişisel veri, ekran görüntüsü, parola, API anahtarı veya özel konuşma içeriği eklemeyin.

## Geliştirme

`main` için doğrudan özellik geliştirmesi yapmayın. Ayrı dallar ve Draft PR kullanın. Test edilmeyen özellikler için kabul iddiasında bulunmayın.
